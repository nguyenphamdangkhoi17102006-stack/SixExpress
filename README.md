Repository này được sử dụng để thực hành quản lý dự án bằng GitHub.

Nội dung thực hành:
- Quản lý công việc bằng Issues.
- Theo dõi tiến độ bằng Milestones và Labels.
- Thực hành tạo nhánh và Pull Request.
- Thực hành liên kết Pull Request với Issue.

Pull Request minh họa được sử dụng để kiểm tra quy trình liên kết Issue và Pull Request.
